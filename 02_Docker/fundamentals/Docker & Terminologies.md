# Docker & Terminologies

Docker is a opensource platform that allows developers to package, distribute, and run applications inside isolated environments called containers.

## Docker Image

The readonly blueprint or template containing the application code, libraries, and dependancies needed to run a software application.

## Docker Container

The live runnable instance of an image that executes the application in an isolated environment

## Docker Host

The physical or virtual machine running Linix or Windows that allocates its hardware resources or execute Docker

## Docker Daemon

The background service running on the host that listens for API requests and manages Docker objects like images and containers

## Docker Client

The command-line tool or user interface used by developer/user to send commands (like docker run) to the Docker Daemon

## Docker Repository

A collaction of different versions(tags) of a specific Docker image, typically stored inside a registary like Docker Hub;
